# TurboCider 视觉系统与组件规范

状态：待实现设计，2026-09-05。配套：[产品与交互](app-product-design.md) · [实现计划](app-implementation-plan.md)。

第二轮补充：[多模态输入与参数](app-inputs-and-parameters.md)。InputAssetStrip 升级为角色明确的输入工作台，支持图片插入/粘贴/拖放与有序多参考；种子默认固定 42，直接可编辑；首版一次一个主输出。

## 1. 视觉语言

关键词：石墨、暖色主操作、清晰排版、大画面、轻分隔、原生交互。整体像认真工作的媒体创作软件；少量品牌色用于主按钮、当前选择、进度，不铺满所有面板。默认跟随系统，也允许独立选择浅色/深色。

参考图具有足够功能密度，但粗边框、层层面板、棋盘背景会争夺画面注意力。TurboCider 用三层不透明中性色建立层次；只有系统侧栏/工具栏按平台外观使用轻材质。内容查看器不使用大范围模糊玻璃，确保视频和图像颜色容易判断。

### 排版和间距

- 字体：系统 SF；中文使用系统中文回退，不附带庞大自定义字体。
- 窗口/页面标题 20–22 pt / semibold；面板标题 13–14 pt / semibold；控件正文 13 pt / regular；辅助 12 pt；主要提示词 14–15 pt。
- 性能数值用 monospaced digits，单位使用正常字重，不让数字跳宽。
- 间距阶梯：4、8、12、16、24、32 pt。面板内边距 16，主要画面周围 24；字段标题与值间隔 6–8。
- 圆角：小标签 6，控件 8，Composer/浮层 12，媒体 8–12；不重复嵌套圆角容器。
- 行高：常规字段 34–36 pt，主操作 38–40 pt，列表行 44–56 pt；图标 16–18 pt，图标按钮有至少 28×28 pt 可点区域。
- SF Symbols 使用一致 regular/medium weight；图标始终配可访问名称，不使用抽象图标代替关键动作文字。

## 3. 窗口与尺寸规则

| 窗口 | 导航 | 查看器/Composer | 参数检查器 |
|---|---|---|---|
| ≥1440 pt | 默认 200，支持 180–240 | 剩余空间，优先最大化媒体 | 默认 300，可 280–360 |
| 1180–1439 pt | 180 | 中间至少 560，必要时缩小边距 | 280，可折叠 |
| 980–1179 pt | 折叠或用户展开 | 占主体，提示词仍可见 | 用户调用时作为暂时覆盖面板 |
| 最小 980×700 pt | 保留菜单/工具栏导航入口 | 媒体弹性缩小，不隐藏主操作 | 独立滚动 |

默认建议 1440×900，确保 1280×800 的完整核心流程。窗口缩放不将整个 UI 等比缩小；表单和字体维持可读。窄屏自动收起行为记忆用户选择，不能反复抖动。未来更小窗口需独立 compact 设计，而不是把全部列挤在一起。

顶部 toolbar 约 48–52 pt；底部运行状态 36–44；Composer 初始 140–180；结果条 72–88，可收起。空间不足先收起结果条、减少媒体边距，再折叠检查器，不能先藏生成按钮。运行详情用 popover 或 Tasks 详情，不长期占据第二个大面板。

## 4. 组件及状态

| 组件 | 内容 | 必需状态与行为 |
|---|---|---|
| StudioNavigation | 4 个主入口 + 设置 | 选中、任务数量、键盘导航 |
| OperationPicker | 图像/编辑/视频 | 能力筛选；不可运行时准确解释 |
| ModelPicker | 名称、可用状态 | 检查中、缺组件、可运行；选择与加载分离 |
| MediaStage | 图像/视频/中间预览 | 空、加载、播放、缺文件、失败、上一结果 |
| InputAssetStrip | 原图/首尾帧角色槽、有序参考、添加/粘贴图片 | 拖放高亮、导入进度、超限待分配、格式错误、未使用素材；支持排序/替换/撤销 |
| PromptComposer | 提示词、输入→单输出摘要、主操作 | 空、有效、导入中、校验中、提交中、生成中禁用；独立取消 |
| ParameterInspector | 模式对应字段、固定/每次随机种子（默认 42） | 默认、修改、无效、被固定、能力变化；每图权重无实现则不显示 |
| RunStatusBar | 阶段/速度/时间 | 等待、未知进度、运行、停止中、断连、终态 |
| PerformancePopover | 阶段耗时/内存/计划 | 无数据、真实采样、过时、估算 |
| ResultStrip | 同草稿结果 | 当前选择、生成中占位、缺文件 |
| ModelDetail | 磁盘/准备/会话 | 分离状态；占用中不能误删 |

不设计只有“理想成功图”的组件。每个组件在代码预览中包含至少空、正常、错误与长文本状态。

## 5. 主界面状态稿说明

### 空状态

媒体区中央使用小尺寸图像符号与“把想法变成画面”；下方两种明确动作“输入提示词开始”“添加参考图”。不铺模型广告或虚假示例作品。未安装模型时主按钮改为“选择可用模型”，完成后返回原草稿。

### 生成中

保留上一结果时必须有“上一结果”标签；底部状态条展示新任务。提供中间预览时贴左上角“中间预览”，完成后才移除标签。参数仍可编辑下一草稿，当前任务详情显示提交快照。

### 完成

画面占据注意力，状态收敛为“完成 · 共用时 xx 秒”，速度细节按需展开。原位出现“编辑此图 / 作为视频首帧 / 导出”，主按钮仍用于继续生成。不要突然弹出遮挡媒体的成功对话框。

### 错误/取消

字段错误靠字段；服务/模型失败在任务状态区解释。用“模型文件已移动”“剩余空间不足”“此规格未准备混合加速”等可行动描述，细节可复制。取消保留草稿和上一结果，不能把历史成功结果染红。

### 模型中心

显示模型名称与用途、一行磁盘状态、一行会话状态。加载中的按钮显示阶段而非假百分比。编译/下载属于可查看的准备任务，有独立取消动作；退出后可恢复的范围由服务能力决定。

## 6. 动效、可访问性与本地化

- 小范围布局/选择切换 120–180 ms；面板 180–220 ms。进度更新温和插值，百分比不能靠动画制造前进。
- 尊重 Reduce Motion / Reduce Transparency；无背景粒子、循环光晕、视频自动播放墙。
- 普通文字目标对比度 ≥4.5:1；大字与非文字状态/控件边界按适用标准验收。禁用态也应让用户读懂原因。
- VoiceOver 可读组件名、素材角色/顺序、模型状态。阶段变化和终态播报，速率每次刷新不播报；详细数值可聚焦读取。
- 键盘：Cmd+N 新草稿，Cmd+Return 生成，Cmd+, 设置；播放区获焦时 Space 播放/暂停。Esc 关闭浮层/退出编辑，不作为无确认的全局取消生成键。
- 初版中文/英文，使用 String Catalog；测试长模型名、双倍英文长度、中文输入法、右侧参数字段展开。说明不只靠 hover。
- 原生对话框完成文件导入/导出；拖放与按钮提供等价路径。错误不以 toast 作为唯一载体。

## 7. 原型范围

随方案提供会话内可交互布局示意：可切图像/编辑/视频、模型页面、任务/素材页面及模拟生成状态；可选浅深主题与强调色。媒体用抽象占位图示，所有速度、进度、历史与模型状态均为演示，不来自本机实测；不接入模型、不下载、不产生媒体、不代表原生功能已完成。

该原型用来评审布局、信息层级、模式切换和性能呈现。正式实现按本规范用原生控件重建，不能将演示数据或演示计时器接到生产状态。
