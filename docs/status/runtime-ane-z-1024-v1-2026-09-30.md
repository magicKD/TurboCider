# Z-Image 1024² BF16 base：runtime v1 与 GPU 同库正反序

接续 [v1 base 图筛选](runtime-ane-v1-base-2026-09-30.md)。那里 Z 的
短序列 1024-row 单层 v1/v2 接口收益只有约 1.2%，不足以据此开展 512² 的
v1/v2 整请求消融。本页检验另一个问题：在 1024² 长序列上，已有
base-only v1 图是否比同库 BF16 GPU 真正加速。不同分辨率与不同对照
不能混报；本轮没有修改 native 源码、已有图或默认路由，只新导出了
单独的 c704 研究图。

## 条件与证据

M4 Max 64 GB；BF16 Z-Image base checkpoint、resident、1024×1024、8 步，
无 adapter；runtime 图 c352/K1024/N512、`chunks=auto`、profile 关闭。
原生库 SHA-256：
`875b0d3dcf5c766feeced21d71f1a366acf0a1238bc3f0ed332098aa3b27b8cd`；
图 manifest SHA-256：
`087d461c171b25e1dc66128a16d1944ffe860a8d22a4505cd80696c469aca5e8`。
每个提示词 GPU→runtime→runtime→GPU，四个独立 CLI batch 各一冷两热；
每个 trial 有独立的 100 ms 进程树采样和 verifier。计时是热请求的
`request_wall`（含 VAE/PNG），不含加载和冷请求。不存在 1024² 匹配
冻结图的本轮样本；现有 512² image-only W8A8 manifest 有原生 512-square
门禁，不用它为 1024² 凑一个冻结图分母。

| 提示词 / seed | GPU 四热样本 (s) | runtime v1 四热样本 (s) | GPU / runtime |
| --- | --- | --- | ---: |
| 灯塔海岸 / 7 | 31.441 / 31.429 / 31.430 / 31.372 | 28.366 / 28.450 / 28.432 / 28.367 | **1.107×** |
| 成年肖像 / 43 | 31.401 / 31.401 / 31.390 / 31.409 | 28.445 / 28.402 / 28.375 / 28.234 | **1.106×** |

各提示词分别池化四个热请求的中位数：灯塔 GPU/runtime
31.429/28.400 s，肖像 31.401/28.388 s。相对 GPU 分别少约
9.64%/9.59% 耗时，均超过设计稿的 5% 整请求初筛门槛。
这不是不同库拼接，也不代表其它设备、分辨率或 prompt 都有同等收益。

原始请求、PNG、逐请求 JSON、内存采样流和 complete summary：

- `outputs/runtime-ane/z-base-1024-v1-gpu-abba-875b/`
- `outputs/runtime-ane/z-base-1024-v1-portrait-abba-875b/`

两组均 `status=complete`。每个 runtime trial 累计 2,583 次真实
prediction、704 个 hybrid block、64 个正常 GPU probe；其中每个热
请求分别增加 1,008 次 prediction、256 个 hybrid block，没有 GPU-only
或错误回退。累计三次 FP16 headroom overflow retry 只在冷请求，scale
稳定在 64，热请求无新增重试；不把冷恢复算成正常热态吞吐。所有八个
内存 verifier 均 complete、swap-in/out 为零、无新增 compression；
runtime 进程树峰值 physical footprint 约 46.24 GB，GPU 约 45.55 GB
（十进制，整个 load+cold+warm+exit 期间）。这不是 Core ML/ANE 独占内存，
不覆盖全部外部服务/驱动或低内存设备资格。runtime 每 trial 的累计
stage 约 3.25–3.41 s，但暴露的 stage wait 只有 0.24–0.29 ms；这些
是宿主侧时序，不是物理 ANE overlap trace，不能把异步 join 全算暴露时间。

已打开两组 GPU/runtime 末次热图：灯塔主体、海岸、光照与浪花、肖像的
人物、卷发、毛衣和窗口构图均接近，局部建筑/波浪或发丝/肤质不同，
没有明显崩坏。同一路线正反向末次热 PNG SHA 相同，GPU 和 runtime
互不逐字节相同。两个提示词的肉眼检查不是广泛画质资格。
`compute_units=cpuAndNeuralEngine` 只是 Core ML 调度策略，遥测仍标记
实际 ANE residency unknown；性能收益本身也不能证明物理放置。

## c704：预测次数下降，但整请求只快 0.38%

为尝试在 1024² 长序列减少循环 Core ML 启动，另导出无 adapter 的
v1 c704/K1024/N512 图，manifest SHA-256 为
`27a385d4ae9f6ecc8d10883bef798bbc5542aebac9aff43000297d9`。
真实 Z BF16 noise_refiner.0 权重、**合成**
4096-row 激活的单层 ABBA 将 ANE/GPU 行数固定为 1408/2688：
c352×4 对比 c704×2。四 trial 各 10 个样本，relative L2 均为
0.001471；并行 FFN 池化中位 45.574→43.571 ms（约 4.4%），
含 staging 47.690→45.732 ms（约 4.1%）。数值、调用数和内存
verifier 均通过，无 overflow retry/swap-in/out，绑定图/模型/探针
前后 SHA 一致。原始证据：
`outputs/runtime-ane/z-c352-c704-1024-component-screen/summary.json`。

随后同一 875b 库、同一个灯塔/seed7、1024²/8 步、无 LoRA、auto、
profile 关闭，按 c352→c704→c704→c352 跑四个独立 resident batch，
每个一冷两热，分别独立采样：

| 图 | 四个热请求 (s) | 四热中位 |
| --- | --- | ---: |
| c352 v1 | 28.377 / 28.435 / 28.423 / 28.288 | 28.400 s |
| c704 v1 | 28.327 / 28.213 / 28.336 / 28.257 | 28.292 s |

c704 的整请求名义少约 **0.38%** 耗时，不足以提升保留级别。
每 trial c352/c704 为 2,545/1,326 次 prediction，但 hybrid block
也分别为 685/704；自适应决策已改变，不能把微图少调用直接换成
整请求节省。四 trial 都 complete，前后绑定输入 SHA 不变、无错误回退，
各只有冷请求的三次 headroom retry。独立采样无 swap-in/out/compression，
同图正反向末次 PNG SHA 相同；两图间 PNG 不同。已打开两图末次热 PNG，
灯塔/海岸/夕阳与波浪构图接近，局部纹理不同。只测一个提示词，
不将微小名义差异当作普遍硬件收益，也不拿上面的单独 GPU campaign
作本组 c704 的 GPU 分母。原始记录：
`outputs/runtime-ane/z-c352-c704-1024-model-abba-875b/summary.json`。
**继续保留 c352**；c704 图仅为本地研究产物，不改 exporter 默认、
产品路由或前一节的性能行。

## 复现与保留决定

从仓库根目录运行 [统一 screen](runtime-ane-validation.md)，使用本机
匹配的 BF16 checkpoint 和 base-only c352/K1024/N512 v1 manifest；
manifest 不含 checkpoint/adapter 权重。分别为两种 prompt/seed 选择
一个尚不存在的 output 目录：

```sh
.venv/bin/python3 tools/validation/runtime_ane_model_screen.py \
  --model models/Comfy-Org-z_image_turbo --model-id z-image-turbo \
  --size 1024 --steps 8 --seed 7 \
  --prompt 'A white lighthouse on a rugged sea cliff at sunset, waves breaking against dark rocks, detailed stonework, dramatic clouds, photorealistic.' \
  --runtime-manifest path/to/z-v1-c352-k1024-n512/manifest.json \
  --routes gpu,runtime,runtime,gpu --chunks auto \
  --warm-repeats 2 --sample-memory --timeout 900 \
  --output outputs/runtime-ane/new-z-1024-abba
```

肖像使用报告上方所述 prompt、seed43 与新 output。图可由离线
`tools/coreml/export_runtime_ane.py` 导出：`--kind swiglu --rows 352
--hidden 3840 --width 10240 --tile-k 1024 --tile-n 512`，不传
`--lora-inputs`。本工作负载可保留 v1 作为显式 optional；默认 GPU、
512² 已测最快冻结图与 runtime LoRA 所需 v2 都不改变。下一步是更多
内容/尺寸的质量与内存压力资格，以及实测硬件放置；不要仅凭本页
开启自动路由或双缓冲权重槽。
