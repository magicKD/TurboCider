# Qwen Image 2.1：512² GPU kernel 消融记录

本轮以已优化的原生 BF16 GPU 路线为对照，使用相同模型、提示词、seed、
输出尺寸、参考图和步数。每条路线独立进程，在 resident Session 中
`prepare`、2 步 warmup 后连续生成两轮；下列时间不含 prepare 和
模型加载。参考图编辑每轮仍重新编码文本与图像。原始请求、逐轮报告
和 PNG 保存在忽略目录 `results/qwen21/session-gpu-*/`；这里只对少量
样本做初步目视/数值对照，不是广泛画质验收或 GPU 性能普适保证。

| 5 步场景 | 默认 GPU 去噪，两轮 | 候选去噪，两轮 | 判定 |
| --- | ---: | ---: | --- |
| 文生图，预合并 Q/K/V 权重为一次投影 | 5.385/5.414 s | 5.417/5.387 s | PNG 逐像素相同，无稳定提速；代码撤回 |
| 双参考编辑，同一 QKV 合并 | 6.124/6.086 s | 6.134/6.082 s | PNG 逐像素相同，无稳定提速；代码撤回 |
| 文生图，借用 Z-Image MPP FFN 投影 | 5.385/5.414 s | 5.371/5.359 s | PNG 逐像素相同，收益不足 1%；代码撤回 |
| 双参考编辑，同一 MPP FFN 投影 | 6.124/6.086 s | 6.066/6.062 s | 收益不足 1%；代码撤回 |
| 文生图，成对 Q/K Metal RoPE | 5.385/5.414 s | 5.319/5.297 s | 去噪约 1.017×，非逐像素相同 |
| 双参考编辑，同一 Metal RoPE | 6.124/6.086 s | 5.999/5.973 s | 去噪约 1.020×，非逐像素相同 |

成对 RoPE 复用仓库现有 `rope_pairs_pair` Metal kernel，把两个 Q/K
旋转合成一次 dispatch；默认仍使用原算子，只有显式设置
`TURBOCIDER_QWEN21_METAL_QK_ROPE=1` 才启用。5 步文生图的 RGB
correlation `0.999428`、RMSE `0.006694`；双参考编辑分别为
`0.999678`、`0.007857`（像素范围 `[0,1]`）。两组 5 步图本身
偏软，不作为最终画质门槛。

相同成对 RoPE 候选又做了 512²/40 步热 Session 对照：

| 40 步场景 | 默认 GPU 去噪，两轮 | Metal RoPE 去噪，两轮 | 两轮合并去噪比 | RGB correlation |
| --- | ---: | ---: | ---: | ---: |
| 文生图 | 42.538/42.584 s | 41.887/41.880 s | 1.016× | 0.999219 |
| 双参考编辑 | 44.169/44.170 s | 43.411/43.401 s | 1.018× | 0.997542 |

40 步两组图目视主体与构图接近；文生图 RGB RMSE `0.011425`，
双参考编辑 `0.020744`。Metal 浮点运算次序有差异，不能称它为
逐位准确的替换。当前只保留诊断 opt-in；约 1–2% 的收益远低于
纯 GPU 期望的 1.1–1.2×，也未覆盖 1/3 参考图、多 seed、1024²、
混合 Core ML 的配对性能/质量对照或设备变化，因此暂不更改默认 GPU 路线。

补充 512²／5 步双参考 W8A8 混合兼容性检查：在同一显式 W8A8
Core ML 前缀、BF16 GPU 后缀、`[3, 5, 7]` GPU-only FFN block 和
256px 参考图配置下，启用成对 RoPE 的热 Session 两轮请求墙钟为
`9.856/9.717 s`，去噪为 `5.712/5.577 s`。每轮 116 次有效 Core ML
调用，累计调用从 warmup 后的 29 次增至 145、261 次；output copy
保持 0，runtime failure 为 0。这只证明候选与混合路径的运行兼容性；
短步请求依然没有端到端加速，不得据此把 RoPE 或 W8A8 设为默认。
原始报告位于 `results/qwen21/session-w8a8-metal-rope-edit2-ref256-512-5/`。
