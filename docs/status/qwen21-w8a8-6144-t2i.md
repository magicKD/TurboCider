# Qwen Image 2.1：6144-channel W8A8 文生图验证

本机 Apple M4 Max、BF16 Comfy checkpoint、512×512 文生图。显式
1024-row、32-block W8A8 Core ML manifest 将每层 FFN hidden `[0,6144)`
交给 `CPU_AND_NE`，剩余 `[6144,12288)` 用 BF16 MLX GPU；prefill
仍为纯 GPU。并行、覆盖率和输出拷贝以运行时计数验证；Core ML 的
`CPU_AND_NE` 策略不证明物理 ANE 驻留。模型由茶壶 FFN 输入校准，
以下两条文生图提示词均未参与此模型的校准。

## 独立生成器：40 步、不同提示词与 seed

同 checkpoint、prompt、seed、采样 schedule 和初始噪声配对；
`qwen21_compare_generations.py` 核对 text、initial、sigmas 张量逐项相同。
此表的后续步中位数不含模型加载，首次完整请求则包含各自的加载
和图像导出，不是 resident Session。

| 提示词 / seed | GPU 后续步 | 6144 W8A8 后续步 | 后续步比 | 首次完整请求 GPU / 混合 | RGB correlation |
| --- | ---: | ---: | ---: | ---: | ---: |
| 雪中狐狸 / 42，29/32 层（3/5/7 GPU 回退） | 1.060 s | 0.764 s | 1.387× | 44.935 / 50.909 s | 0.98972 |
| 雪中狐狸 / 42，全 32 层 | 1.060 s | 0.732 s | 1.448× | 44.935 / 40.529 s | 0.98781 |
| 玻璃瓶与仙人掌 / 17，全 32 层 | 1.061 s | 0.733 s | 1.447× | 45.291 / 40.362 s | 0.99224 |

29/32 和 32/32 的实际调用数分别为 `39×29=1131` 与
`39×32=1248`，output copy 均为 0。全 32 层狐狸对 GPU 的
RGB RMSE `0.04337`，玻璃瓶与仙人掌为 `0.02799`（归一化像素）。
目视两组场景主体、位置与整体光照接近，毛发、瓶口和仙人掌刺等
局部细节不同；这不是任意 prompt/seed 的质量认证。单次冷请求
受模型加载和系统缓存影响明显：29/32 层狐狸甚至慢于 GPU，
不能将后续步比作为首次请求比。

## 正式常驻 Session：狐狸文生图

正式 CLI 请求在各路线独立进程内先 `prepare`、2 步 warmup，再
连续两轮**相同提示词缓存命中**；记录墙钟含 VAE decode 和 PNG
导出，不含准备和模型加载。显式 W8A8 使用 BF16 GPU 后缀和
全部 32 层 ANE FFN，没有编辑路线的 3/5/7 GPU 回退：

| 步数 | GPU 两轮墙钟 | 6144 W8A8 两轮墙钟 | 两轮中位墙钟比 | 每轮 Core ML FFN 调用 |
| ---: | ---: | ---: | ---: | ---: |
| 5 | 5.999 / 5.997 s | 5.042 / 4.820 s | 1.216× | `4×32=128` |
| 40 | 43.184 / 43.223 s | 30.468 / 30.489 s | 1.418× | `39×32=1248` |

两轮各路线 PNG 逐字节一致；5 步 GPU/混合 RGB correlation
`0.99598`、RMSE `0.02107`，40 步则为 `0.97119`、RMSE
`0.06909`。40 步狐狸主体仍清晰、构图接近，尾部和腿部有明显
局部差异，不能宣称逐像素或局部语义完全保持。5 步图不替代
40 步质量检查。另用 `--dump-tensors` 重复 5 步请求，文本和初始
噪声张量逐字节匹配；两路线的 PNG SHA 也分别与不转储版本相同。
这证明所比的 5 步请求输入相同，不能推导其他 seed 的普适提速。

本地原始证据位于被忽略的 `results/qwen21/`：
`qwen21-w8a8-w6144-{heldout-fox,full32-fox,heldout-glass}-*`、
`session-{gpu,w8a8-w6144}-fox-t2i-512-{5,40}-cache/`、
`session-{gpu,w8a8-w6144}-fox-t2i-512-5-dump/` 和相应的
`*-comparison.json`。诊断生成器已允许 6144-channel W8A8，
但仅允许 1024 行（512²），不把它扩展到未经校准的 1024²；
正式 CLI 已允许显式 W8A8 文生图请求，`plan` 验证了 32/32 覆盖率。
默认仍为 BF16 GPU；更多 prompt、seed、机器和物理 ANE 驻留检查
未完成。512² 编辑的 32/32 与 29/32 质量和速度取舍另见
[全覆盖编辑对照](qwen21-w8a8-full32-edit.md)。
