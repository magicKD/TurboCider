# Qwen Image 2.1：倒数第二步半层 FFN 复用消融

目标是继续提高 512²／5 步的纯 GPU 吞吐量。只在同时显式设置
`TURBOCIDER_QWEN21_GPU_REUSE_FINAL_FFN=1` 与
`TURBOCIDER_QWEN21_GPU_REUSE_PENULTIMATE_EVEN_FFN=1` 时使用；
本次对照还设置 `TURBOCIDER_QWEN21_METAL_QK_ROPE=1`。请求仍须
`execution=gpu`、`allow_approximation=true`、512×512；编辑只接受
1–3 张 256px 参考。默认纯 GPU 和 GPU/ANE 完全不变。

在第 N−3 步完整算并记录 32 层 FFN；第 N−2 步复用偶数层
（0,2,…,30）上一步的 FFN 输出，奇数层照常计算，再记录这一步
32 层实际使用的输出；最后一步复用全部 32 层输出。attention、
modulation 和残差每一步仍用当前输入计算。于是偶数层 FFN 输出
在最后一步最多跨越两个 denoise 步；这**是近似，不是等价 kernel
fusion 或 KV cache**。短于 4 步的内部预热不会执行这个实验分支。
请求私有缓存于条件失效时清除，不跨请求传递；计划和运行结果分别
记录 `qwen21_gpu_reuse_penultimate_even_ffn` 和所选路线。

独立进程 prepare、2 步 warmup，再对同一条件连续生成两次；墙钟
包括 VAE/PNG 和相同输入张量转储，不含准备或首次加载。比较器
逐项核验文本、初始噪声及编辑的每张 reference 张量一致。

| 512² 场景 | 默认 GPU 两轮 | 原最快 GPU：成对 RoPE＋末步 FFN 复用 | 本候选两轮 | 对默认 GPU | 对原最快 GPU |
| --- | ---: | ---: | ---: | ---: | ---: |
| 狐狸文生图，5 步，31-token 提示词 | 5.986/5.999 s | 5.229/5.203 s | 4.879/4.894 s | **1.226×** | **1.067×** |
| 1 参考编辑，5 步 | 6.297/6.314 s | 5.535/5.540 s | 5.171/5.177 s | **1.219×** | **1.070×** |
| 2 参考编辑，5 步 | 6.700/6.702 s | 5.891/5.905 s | 5.559/5.569 s | **1.204×** | **1.060×** |
| 3 参考编辑，5 步 | 7.086/7.072 s | 6.278/6.298 s | 5.936/5.930 s | **1.193×** | **1.060×** |
| 2 参考编辑，40 步 | 44.718/44.743 s | 43.310/43.311 s | 42.983/42.979 s | **1.041×** | **1.008×** |

以上各路线在同一场景的 prompt、seed、步骤、reference resize 与
输入张量匹配；但文生图使用的提示词与先前 24-token 狐狸测试不同，
不得把两者时间直接相除。相对先前最快 GPU：5 步文生图／1／2／3
参考的 RGB correlation 分别约 0.99505／0.99933／0.99804／
0.99674，归一化 RGB RMSE 约 0.02331／0.01182／0.01906／
0.02671；40 步双参考为 0.99983／0.00544。狐狸的整体构图
保留，但 5 步原图本来较软，局部毛发不同。单／双壶仍可辨，三参考
龙贴纸的眼睛及轮廓出现可见变化；不声称严格忠于参考图，尤其
单参考哑光红色要求原 GPU 也没有达到。40 步双壶目视非常接近。
此前连续两步**所有层** FFN 复用导致狐狸明显模糊，已撤回；本次
只在倒数第二步复用半数层，不能据此推断更多 prompt 和 seed 的
结果一定合格。

相同 5 步双参考输入下，现有 6144-channel／32 层 W8A8 GPU/ANE
仍约 5.459/5.414 s，比本次纯 GPU 5.559/5.569 s 略快；混合
模式的量化和画质取舍不同，旧混合报告未转储同轮输入，严格的
跨路线张量逐项对照及物理 ANE 驻留仍待验证。40 步该混合路线
约 31.962/31.985 s，远快于本次的约 42.98 s。因此本次 5 步
加速不能代替持续 FFN GEMM 优化或 GPU/ANE 并行研究。

`TURBOCIDER_NATIVE_ONLY=1 tools/native/build.sh`、`make test-qwen21`
通过；正式 CLI `plan` 和 5 步文生图 `generate` 均完成，导出有效
PNG，报告显示 GPU 执行和两种 FFN 近似标记。它是功能冒烟，不以
一次冷进程时间替代上述暖请求速度。原始逐轮报告、PNG、转储、
配对 JSON 在忽略目录 `results/qwen21/session-gpu-penultimate-even-*`，
CLI 图片在 `results/qwen21/cli-gpu-penultimate-even-512-5.png`。
仅作为显式实验选项保留，默认不开启。
