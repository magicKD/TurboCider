# Qwen-Image-2.1 W8A8 实验归档

本目录统一保存 M4 Max 上冻结 W8A8 Core ML FFN 与 BF16 GPU 分区的历史测量。
记录覆盖离线单层/32 层检查、独立生成器和常驻 Session；原文件名及正文日期保留。
这些实验解释当时的实现与观察，不代表当前版本的默认、准入或发布资格。
当前使用方式见 [Qwen 用户指南](../../public/QWEN_IMAGE_21.md)，后续路线见
[加速决策入口](../../status/acceleration.md)。
