# Qwen-Image-2.1 缓存实验归档

本目录保存 2026-09-27–30 的残差复用、编辑前缀 K/V 和 DiT cache
记录。它们具有不同生命周期、执行路线、输入规模和质量边界；编译缓存、
文本条件缓存、跨请求前缀缓存和一次采样内的有损残差复用不能混为一谈。
