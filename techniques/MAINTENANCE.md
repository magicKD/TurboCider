## 定位与保留范围

保留：方法、公式、伪代码、小型教学实现、固定版本源码/论文链接、案例结论、失败教训与适用边界。

不保留：任何 JSON/JSONL/NDJSON、完整实验数组、逐轮计划/日志、trace、编译产物、原件/hash 证明链、采集驱动、专用验证器或实验回归包。也不要将它们换成 YAML、TOML 或长文本继续提交。

知识库的验收是内容可理解、来源可定位、链接和检索可用；不是为读者重建实验环境。学习笔记可以尚未实测，案例数字也不因为入库而获得当前性能或质量资格。

## 来源与代码

来源精简为可读的固定 revision、关键文件/函数和阅读重点。小型代码留在 [examples](examples/README.md)，用于理解数学、数据流或状态机；原项目实现从来源链接阅读，不镜像完整第三方仓库。

稳定 ID 与主题直接放在 Markdown 注释中；检索自动扫描页面，不维护第二套 JSON 登记。生成索引只是一份阅读视图。

## 实验与恢复

需要实验时，工作目录使用仓库根的 `outputs/`，任务结束只提炼认识。当前知识库不承诺提供旧实验原件或可复算证据；不能把链接检查通过称为模型验证通过。

2026-10-17 轻量化前的完整 techniques 快照保存在本地被忽略的 `outputs/techniques-lightweight-20261017-aecbb7d/before.tar.gz`，旧提交另有本地备份分支 `backup/techniques-before-lightweight-20261017`。这些备份不属于知识库，也不随普通 dev-tech 推送上传。恢复时先解包到新目录，不覆盖当前内容。

本次只修订尚未推送的提交，不重写已发布历史，不执行远端 push。旧 Git 对象可因本地备份继续占空间，但不会因此进入普通分支推送的新增对象集合。
